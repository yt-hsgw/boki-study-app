# 簿記3級 学習支援アプリ

仕訳問題の練習・管理ができる Web アプリケーションです。

## 機能

### 仕訳問題
- **問題入力**: 仕訳問題を登録（選択肢モード / 自由記入モード）
- **複合仕訳対応**: 借方・貸方それぞれ複数行の入力が可能
- **問題一覧**: 登録した問題の閲覧・削除
- **答え合わせ**: 正解との比較・確認
- **下書き保存**: 入力中のデータを自動保存

### 問題集
- **問題集作成**: 自由なテキスト/画像で問題・回答を作成
- **練習モード**: 作成した問題集を練習
- **再挑戦機能**: 間違えた問題をランダム順で再挑戦
- **進捗表示**: 正答率・正解数・不正解数を確認

### ツール
- **用語集**: 150以上の簿記用語を検索・閲覧（フローティングパネル）
- **簡易電卓**: 画面左下のフローティングボタンから四則演算が可能

## 問題集機能の使い方

### 作成モード
1. 「問題集」タブを開く
2. 「新規作成」ボタンをクリック
3. 問題集の名前を入力
4. 「問題を追加」で問題を追加
5. 各問題で「テキスト」または「画像」を選択
6. 問題文と回答を入力
7. 「保存」をクリック

### 練習モード
1. 問題集一覧から練習したい問題集の▶ボタンをクリック
2. 問題が表示されたら、回答を考える
3. 「表示」をクリックして回答を確認
4. 「正解」または「不正解」をクリック
5. 全問終了後、結果を確認
6. 「間違えた問題を再挑戦」で復習

## 勘定科目

80以上の勘定科目に対応しています。選択または自由入力が可能です。

| カテゴリ | 科目例 |
|---------|--------|
| 資産 | 現金、普通預金、当座預金、売掛金、貸付金、商品、建物、車両運搬具、差入保証金 |
| 負債 | 支払手形、買掛金、借入金、未払金、預り金、所得税預り金、仮受金、貸倒引当金 |
| 純資産 | 資本金、引出金、利益準備金、繰越利益剰余金 |
| 収益 | 売上、商品売買益、受取利息、受取手数料、受取家賃 |
| 費用 | 仕入、給料、法定福利費、広告宣伝費、旅費交通費、消耗品費、減価償却費、租税公課 |

## 用語集のカスタマイズ

用語を追加・編集する場合は `public/glossary.csv` を編集してください。

```csv
term,reading,category,definition
用語名,よみがな,カテゴリ,説明文
```

## データ保存

- データは `localStorage` に保存されます
- 画像データも含めて保存されます（大きな画像は5MB以下推奨）
- ブラウザのデータをクリアすると全データが削除されます
